# МЕЖПАР

**МЕЖПАР** — открытая веб-платформа для учебных групп. Идея — объединить расписание и дедлайны с разговорами и небольшими планами, из которых складывается жизнь группы.

> **Текущая версия: локальный MVP-предпросмотр.** Интерфейс и основные действия работают в браузере и сохраняются в его локальном хранилище. На опубликованном предпросмотре нет регистрации, общего сервера, настоящих участников группы или синхронизации между устройствами. Все имена, пары, публикации, задания и встречи — демонстрационные.

## Что уже работает

- Адаптивный обзор группы и нижняя навигация на телефоне.
- Расписание по дням и неделям, чётность/нечётность; добавление, изменение и удаление демонстрационных пар.
- Задания с дедлайнами и локальной отметкой выполнения.
- Лента группы: публикации, реакции и комментарии.
- Поиск по расписанию, заданиям, ленте и материалам.
- Материалы, пример списка участников, встречи и локальные отметки «Пойду».
- Светлая, тёмная и системная темы; уменьшение анимаций; поиск с клавиатуры (`Ctrl/⌘ + K`).
- PWA-манифест, установка на главный экран и service worker для статических файлов.
- Экспорт локальных данных в JSON и восстановление демо-набора.

Предпросмотр в интерфейсе явно помечен как демонстрационный. Локальные изменения не видны одногруппникам и не синхронизируются с другими браузерами.

## Локальный запуск

Нужны Node.js 20.19+ или 22.12+ и npm.

```sh
npm ci
npm run dev
```

Адрес локального приложения появится в терминале. Для предпросмотра файл `.env` не нужен.

```sh
npm run lint
npm run typecheck
npm test
npm run build
npm run preview
```

## Публикация статического предпросмотра

Публичный репозиторий можно разместить на GitHub Pages в GitHub Free. Workflow `deploy-pages.yml` собирает приложение и публикует каталог `dist/` по HTTPS при обновлении `main`. Один раз включи **Settings → Pages → Build and deployment → GitHub Actions**.

Сайт будет доступен по адресу `https://pluseight8.github.io/mezhpar/`. Домен и платные сервисы не нужны. Путь проекта уже учтён в сборке, манифесте PWA и статических файлах.

### Выбор хостинга и ограничения

| Вариант | Что даёт бесплатный план | Важные ограничения | Решение |
| --- | --- | --- | --- |
| GitHub Pages | Статические файлы из публичного репозитория, HTTPS, без базы данных и хранилища пользовательских данных | Опубликованный сайт до 1 ГБ; рекомендованный размер репозитория до 1 ГБ; мягкий лимит трафика 100 ГБ/месяц; мягкий лимит стандартной сборки — 10 в час, но он не применяется к собственному GitHub Actions workflow | Выбран для предпросмотра без аккаунтов; backend не запускает. |
| Cloudflare Pages + D1 | Статический хостинг и необязательный backend на Workers/SQLite | Pages Free: 500 сборок в месяц, тайм-аут сборки 20 минут, до 20 000 файлов на сайт. После дневного бесплатного лимита чтения/записи D1 перестаёт выполнять запросы. | Технически подходит, но не решает локализацию российских персональных данных. |
| Supabase Free | PostgreSQL, Auth, Storage и API | Квота базы 500 МБ; после примерно 7 дней низкой активности бесплатный проект может быть приостановлен. В опубликованном списке регионов Supabase нет России. | Не включён для реальных данных российских студентов. |

Лимиты могут измениться — перед запуском и ростом аудитории перепроверь официальную документацию. Доступность GitHub Pages и Cloudflare Pages из российских сетей **не проверена через российское подключение**. Наличие HTTPS-ссылки не гарантирует доступность у всех операторов.

Источники: [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages), [лимиты Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits), [лимиты Cloudflare Pages](https://developers.cloudflare.com/pages/platform/limits/), [цены Cloudflare D1](https://developers.cloudflare.com/d1/platform/pricing/), [пауза бесплатного Supabase](https://supabase.com/docs/guides/platform/free-project-pausing), [регионы Supabase](https://supabase.com/docs/guides/platform/regions), [квоты Supabase](https://supabase.com/docs/guides/platform/billing-on-supabase).

## Что нужно для реального запуска группы

Миграция в `supabase/migrations/` описывает будущие таблицы и политики PostgreSQL RLS. В этой версии браузерное приложение **не обращается к Supabase**; миграция не применялась и не проходила интеграционные тесты. Не загружай сюда реальные персональные данные и не представляй backend как готовый.

Для российской группы важна статья 18, часть 5 Федерального закона № 152-ФЗ: в общем случае первичная запись, систематизация, накопление, хранение, уточнение и извлечение персональных данных граждан РФ должны выполняться с использованием баз данных в России, за предусмотренными законом исключениями. В актуальном списке регионов Supabase российского региона нет. До сбора имён, адресов почты, профилей, публикаций и сообщений нужно выбрать подходящий российский backend и получить квалифицированную консультацию по уведомлению оператора, политике обработки данных, основанию и согласию, удалению и защите данных. Этот репозиторий не является юридическим заключением и не заявляет о соответствии закону.

Источники: [текущая редакция статьи 18 на сайте Минтруда](https://mintrud.gov.ru/docs/laws/130), [статья 22 об уведомлении регулятора](https://www.consultant.ru/document/cons_doc_LAW_61801/d996966e22e1320c9de1ab82d9f6be12c3d9d765/), [портал Роскомнадзора по персональным данным](https://pd.rkn.gov.ru/), [регионы Supabase](https://supabase.com/docs/guides/platform/regions).

SQL — заготовка архитектуры, а не подтверждение безопасности. Перед подключением клиента проверь все политики RLS на отдельном тестовом проекте PostgreSQL/Supabase. Никогда не помещай ключ `service_role` в код браузера.

## Исследование продукта

- [Studo](https://studo.com/en/welcome) сочетает календарь и расписание вуза с почтой, чатом, курсами и университетскими сервисами; доступность зависит от учебного заведения.
- [MyStudyLife](https://mystudylife.com/tour/) силён как личный планировщик: расписание, задания, дедлайны, чередование недель и напоминания.
- Первая гипотеза МЕЖПАР — общая группа, куда студентов возвращают расписание и дедлайны, а лента, комментарии, материалы и встречи добавляют социальный слой. Этот предпросмотр проверяет интерфейс, но ещё не спрос студентов.

## Структура

```text
src/                 React + TypeScript и локальная модель данных
public/              PWA-манифест, иконка и статический service worker
supabase/migrations/ Схема будущей базы и RLS-политики
docs/                Архитектура, администрирование группы и данные
.github/workflows/   CI-проверки и публикация GitHub Pages
```
